# AbsoluteCenter

Positions its children centered and absolutely filling the nearest positioned ancestor. Useful for overlays and badges centered on top of other content.

<PreviewPair>
<ComponentPreview>

    <AbsoluteCenter>
      <Box bg="brand" w={32} h={32} rounded="r-2" />
    </AbsoluteCenter>
  </Box>
</ComponentPreview>

## Props

AbsoluteCenter accepts every Box prop except `style` (its `position: 'absolute'` inset styling is fixed internally). `align` and `justify` default to `'center'` but can be overridden. See Box's props for the full list, including `gap`, spacing (`m*`/`p*`), `bg`, and `rounded`.
