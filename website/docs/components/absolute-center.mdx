# AbsoluteCenter

Positions its children centered and absolutely filling the nearest positioned ancestor. Useful for a loading state or empty state centered on top of other content — e.g. a spinner over a card while it loads, or a modal's content centered on its scrim.

## Props

AbsoluteCenter accepts every Box prop except `style` (its `position: 'absolute'` inset styling is fixed internally). `align` and `justify` default to `'center'` but can be overridden. See Box's props for the full list, including `gap`, spacing (`m*`/`p*`), `bg`, and `rounded`.
