# Alert

An inline banner for surfacing status messages, with five semantic variants and an optional dismiss action.

## With leading and dismiss icons

`icon` renders any element before the text — pass a `TVajraIconComponent` from `vajra-ui-icons` (or your own). `dismissIcon` replaces the default ✕ glyph on the dismiss button.

<PreviewPair>
<ComponentPreview>
  <Alert
    variant="info"
    title="Update available"
    message="Restart the app to apply the update."
    icon={<InfoIcon size={20} width={20} height={20} color="#3b82f6" />}
    onDismiss={() => {}}
    dismissIcon={XIcon}
  />
</ComponentPreview>

```tsx
import { InfoIcon, XIcon } from 'vajra-ui-icons';

<Alert
  variant="info"
  title="Update available"
  message="Restart the app to apply the update."
  icon={<InfoIcon size={20} width={20} height={20} color="#3b82f6" />}
  onDismiss={() => {}}
  dismissIcon={XIcon}
/>
```
</PreviewPair>

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `message` | `string` | — | Required. Body text of the alert. |
| `title` | `string` | — | Optional heading rendered above the message. |
| `variant` | `'default' \| 'success' \| 'error' \| 'warning' \| 'info'` | `'default'` | Semantic color scheme for background, border, and text. |
| `onDismiss` | `() => void` | — | When provided, renders a dismiss (✕) button. |
| `icon` | `React.ReactNode` | — | Optional leading icon element rendered before the text. |
| `dismissIcon` | `TVajraIconComponent` | — | Icon shown in the dismiss button, when `onDismiss` is set. Defaults to a plain ✕ glyph. |
| `testID` | `string` | — | Test identifier forwarded to the root container. |
