# Toast

A queued, auto-dismissing message anchored to the top or bottom of the screen. Wrap your app (or the preview) in `ToastProvider`, then call `useToast().show(...)` from anywhere inside it.

export const ToastDemo = () => {
  const { show } = useToast();

  return (
    <Row gap="s-2" wrap="wrap">
      <Button label="Default" onPress={() => show('Saved successfully.')} />
      <Button
        variant="solid"
        label="Success"
        onPress={() => show({ message: 'Profile updated.', variant: 'success' })}
      />
      <Button
        variant="outline"
        label="Error"
        onPress={() => show({ message: 'Something went wrong.', variant: 'error' })}
      />
      <Button
        variant="subtle"
        label="Persistent"
        onPress={() => show({ message: 'This stays until dismissed.', duration: 0 })}
      />
    </Row>
  );
};

## Props

### ToastProvider

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | | Required. Subtree that gets access to `useToast()`. |
| `position` | `'top' \| 'bottom'` | `'bottom'` | Where the toast is anchored on screen. |

### useToast()

| Return | Type | Description |
|---|---|---|
| `show` | `(options: TToastOptions \| string) => string` | Enqueues a toast. Accepts a plain message string or a `TToastOptions` object. Returns the generated toast id. |
| `hide` | `(id: string) => void` | Removes a queued/visible toast by id. |

### TToastOptions

| Prop | Type | Default | Description |
|---|---|---|---|
| `message` | `string` | | Required. Toast text. |
| `variant` | `'default' \| 'success' \| 'error' \| 'warning' \| 'info'` | `'default'` | Visual style. |
| `duration` | `number` | `3000` | Milliseconds before auto-dismiss. Pass `0` to disable auto-dismiss. |

Only one toast is shown at a time; additional calls to `show` are queued and displayed in order. `useToast` throws if called outside a `ToastProvider`.
